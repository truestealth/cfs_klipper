# Подготовка локальной установки

[English](installation.md)

Проверенный на ПК инструмент копирует каркас разработки в локальный каталог
Klipper `extras`. **Загрузчик по-прежнему отказывает в активации.** Компонентные
тесты не подтверждают готовность принтера; для будущей проверки на принтере
потребуются отдельное разрешение и проверка оборудования. Инструмент не
подключается к принтеру, не управляет службами и не изменяет конфигурацию,
макросы, прошивку или данные.

Запускайте из этой копии проекта с Python 3.8 или новее. Оба пути обязательны;
каталог extras и родительский каталог резервной копии должны существовать.
Сам путь резервной копии должен отсутствовать и находиться отдельно от extras.
Нужен существующий обычный `extras/box.py`; `extras/cfs` должен отсутствовать.
Ссылки, точки повторной обработки и переходы к родительскому каталогу запрещены.
Нативные точки входа `box.so`, `box.*.so`, `box.pyd` и `box.*.pyd` запрещены,
поскольку они могут перекрывать `box.py`; `box_wrapper.so` сохраняется.
Действие по умолчанию только показывает план:

```sh
python tools/install.py --extras /path/to/klipper/klippy/extras --backup /path/to/new-backup
python tools/install.py install --extras /path/to/klipper/klippy/extras --backup /path/to/new-backup
python tools/install.py restore --extras /path/to/klipper/klippy/extras --backup /path/to/new-backup
```

Установка сохраняет исходные байты `box.py`, права и временные метки вместе с
манифестом хешей, затем копирует только фиксированный список файлов Python.
Соответствующие файлы CPython `extras/__pycache__/box.cpython-*.pyc` сохраняются
и удаляются перед заменой исходного файла; восстановление удаляет созданные
соответствующие кеши и возвращает исходные байты, права и временные метки.
Остальные записи кеша не изменяются.
Существующие `box*.so`, `serial*.so`, остальные extras и данные пользователя не
изменяются. Восстановление проверяет резервную копию и все установленные файлы
и отказывает при их изменении или наличии дополнительных записей в `cfs`, кроме
обычных файлов байткода CPython установленных модулей в `cfs/__pycache__`:
они удаляются. Неизвестные записи кеша и ссылки запрещены.
Восстановленные байты проверяются, резервная копия сохраняется. Берегите её:
хеши обнаруживают случайные изменения, но не подтверждают подлинность
умышленно изменённого манифеста.

При ошибке установки инструмент пытается отменить уже сделанные изменения;
каталог резервной копии остаётся для проверки. При ошибке восстановления может
понадобиться ручное восстановление из `box.py.original`; не удаляйте его. Во
время операций никто другой не должен изменять целевой каталог: инструмент не
блокирует другие процессы и не обеспечивает транзакцию при потере питания.
